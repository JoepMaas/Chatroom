How would you describe your product?

General Description
A fully customizable chat room.
Where you can add text, photos, and make your own custom styles.
You can customize your profile, see other's profiles.
You have randomized themes with random colors
Designs

Advanced theme system with changeable colors, styles, and automatic matching across the entire interface
Custom styles per chat (toggleable)
Clean, modern chatroom design that adapts to user themes


Requirements / User Stories

As a user I want to create and login to an account, so my data is saved and synced.
As a user I want to create and edit a custom profile - photo, username, display name, bio.
As a user I want to view other users’ profiles, including their bio and profile pic.
As a user I want to send text, photos, and links in the chat.
As a user I want to tag/mention people in messages.
As a user I want a dedicated UI for searching messages to easily find messages.
As a user I want to create, adjust, save, and load themes, with colors that automatically match across the whole UI.
As a user I want the ability to randomize colors for theme generation.
As a user I want my data to be saved and accessible.
As a user I want to get message when somebody tags me.


Must Have

User login
Custom profile (photo, username, display name, bio, color)
Real-time messaging (text, photos, links)
Theme system: changing/saving themes, adjusting colors & styles with automatic matching
Message history storage & sync
Basic search functionality for messages
User list
Persistent data storage (userID, userdata, themes, chats)


Should Have
View other users’ profiles
Dedicated search UI for messages
Tagging / @mentions
Color randomizer
Adjusting basic colors with cohesive matching
Changeable colors and styles for different UI sections



Could Have

User blocking and message deletion
More advanced theming options
Draggable & fully customizable UI layout
Notifications
Private DMs
Background sounds

Won’t Have 

Video calling
