# README

## Custom styles
You can change every color in the home page, including: "Sidebar, messages, buttons, background, accent, text and secondary colors."
You can also press a randomize button and then every color gets randomized and fit to each other, so not totally random.

## Custom formatting

### youtube links
sending youtube links with "::" after sends the video from that youtube link

### images/gifs
put the image or gif link in double square brackets "[[]]" to send the image, use double brackets afterward "(())" to add alt text, these are not neccesary

### audios
put the audio url in between double curly brackets "{{}}" to send the audio

## Joining groups
you can join groups by sending the text "/goto GROUPNAME" where GROUPNAME is replaced with the group you want to join, it can contain spaces
you can also send "<goto>GROUPNAME</goto>" to send a button linking that group
